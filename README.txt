منظومة العضويات المركزية – كيان شباب بحري
==========================================

محتويات المشروع:
- index.html: واجهة الموقع وصفحاته.
- style.css: التصميم المتجاوب.
- script.js: التنقل وربط أزرار النماذج.
- assets/: شعارات الكيان ووزارة الشباب والرياضة.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.
3) لرفع الموقع مجانًا يمكن نشر المجلد على GitHub Pages بعد إنشاء مستودع.

روابط Microsoft Forms الحالية:
- عضو جديد: مضافة في script.js.
- عضو حالي: مضافة في script.js.

تنبيه مهم – حالة النسخة:
هذه نسخة واجهة أولية (Front-end prototype). روابط المحافظات حاليًا تفتح نموذج العضو/التحديث العام نفسه؛ لا يوجد حتى الآن نموذج مختلف لكل محافظة.
لوحة التحكم المعروضة معاينة تصميمية ولا تعرض أرقامًا حقيقية، ولا يوجد تسجيل دخول أو قاعدة بيانات متصلة في هذه النسخة.

لتحقيق لوحة تحكم خاصة وتحديث تلقائي فعلي:
- ربط ردود كل Microsoft Form بمصدر بيانات منظم مثل Excel Online / SharePoint.
- إعداد تدفق Power Automate لمعالجة كل رد.
- إجراء مطابقة الرقم القومي على الخادم أو داخل بيئة بيانات محمية، مع عدم إرسال الرقم القومي إلى JavaScript أو تخزينه في المتصفح.
- بناء API أو خدمة خلفية محمية بالمصادقة لتغذية لوحة التحكم.
- اختبار صلاحيات الوصول والنسخ الاحتياطي ومنع التكرار قبل نشر بيانات حقيقية.

الأمان والخصوصية:
لا تستخدم هذه النسخة وحدها لجمع أو عرض بيانات شخصية حساسة. لا تضع الرقم القومي أو كلمات المرور داخل ملفات HTML أو CSS أو JavaScript. يجب قصر الوصول إلى بيانات الهوية على حسابات مخولة، وتحديد مدة الاحتفاظ والنسخ الاحتياطي وفق سياسة الكيان والقوانين المعمول بها.

ملاحظة: الشعارات المرفقة مأخوذة من الصور التي أرسلها المستخدم في المحادثة.
